# CMHS VarEnrich quick start

This package runs locally and does not require Python, Conda, or an internet connection.

## Start

- macOS: double-click **Start CMHS VarEnrich.command**.
- Windows: double-click **Start CMHS VarEnrich.bat**.
- Linux: run `./Start-CMHS-VarEnrich.sh`.

Select a query file, a tested-gene background universe, and a GMT annotation collection. Reports are saved under `Documents/CMHS-VarEnrich-Results`.

## Security notices

Preview builds may be unsigned. Verify the adjacent `.sha256` checksum before bypassing an operating-system warning. Permanent warning-free distribution requires Apple notarization and trusted Windows code signing.

The software is for research use and is not validated for diagnosis or clinical decision-making.

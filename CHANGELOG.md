# Changelog

## 0.1.0 — 2026-09-15

- Added gene-list, delimited variant-table, VEP/SnpEff VCF, and VCF.GZ inputs.
- Added explicit-universe one-sided hypergeometric/Fisher enrichment and BH-FDR.
- Added odds ratios, confidence intervals, contributing-gene evidence, and filter metadata.
- Added direct builders for GO, HPO, Reactome, ClinVar disease, and custom annotations.
- Added checksummed resource manifests and an explicit public-resource downloader.
- Added private localhost GUI, searchable HTML reports, and publication SVG figures.
- Added synthetic demonstrations, cross-platform CI, standalone packaging, and smoke tests.
